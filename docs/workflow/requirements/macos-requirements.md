# Требование для macOS

Чтобы собрать репозиторий на macOS, необходимо установить инструменты разработчика `Xcode` и несколько других зависимостей, представленных ниже.

## Инструменты разработчика Xcode

-   Установите инструменты разработчика Apple Xcode из [Mac App Store](https://apps.apple.com/app/xcode/id497799835).
-   Настройте инструменты командной строки Xcode. Обычно настройка выполнена по умолчанию. В противном случае, настройка выполняется двумя способами:
    -   Через интерфейс: Запустите Xcode, откройте Настройки (Preferences) и на вкладке Расположение (Locations) измените `Command Line Tools`, чтобы указать на установку _Xcode.app_.
    -   Через терминал: выполните команду `sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer`. Эта команда предполагает, что приложение _Xcode_ называется `Xcode.app`. Если вы переименовали его во что-то другое, скорректируйте путь, а затем выполните команду.

## Дополнительные зависимости

Для сборки репозитория также необходимо установить следующие зависимости:

-   `CMake` 3.20 или новее
-   `icu4c`
-   `openssl@1.1` или `openssl@3`
-   `pkg-config`
-   `python3`
-   `ninja` (Установка опциональна. Позволяет собирать нативный код с использованием `ninja` вместо `make`)

Вы можете установить каждый пакет по отдельности или, в качестве альтернативы, установить _Homebrew_ и использовать `Brewfile`, представленный внутри репозитория. При использовании Homebrew, используйте следующую команду из корневой папки репозитория, чтобы установить все зависимости:

```bash
brew bundle --no-lock --file eng/Brewfile
```
